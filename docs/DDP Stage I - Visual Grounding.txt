Single-stage vs. Two-stage Approaches
Two-stage approaches:
First generate a set of sparse region proposals and then exploit region-expression matching to find the best one
Either binary classification loss or maximum-margin ranking
High accuracy but computationally expensive
One-stage approaches: 
Perform visual-linguistic fusion at intermediate layers of an object detector and output the box with maximal score over pre-defined dense anchors
Linguistic context is densely fused with the visual features, bounding box prediction in a sliding-window manner
Faster and Simpler architecture, with potentially lower accuracy

Transformer-based Approaches
TransVG
Reformulate the visual grounding as a direct coordinates regression problem and avoid masking predictions out of a set of candidates, outputs a 4-dim coordinates to ground the object
Separate encoding for video and linguistic features, then append a multi-modal learnable token [REG] for Visual-Linguistic Transformer
The appended token is leveraged to directly predict the 4 dim coordinates of the referred object
Visual Branch: ResNet is used as the convolutional backbone network, and initialized with the encoder of DETR model  with 6 transformer encoder layers, with 8 heads in multi-head self-attention
Linguistic Branch: BERT is used to generate the features and a similar transformer structure as the visual branch
Visual-Linguistic Fusion Module: The visual and linguistic tokens are concatenated and appended with learnable token

Visual Grounding with Transformers
Approach is to learn semantic-discriminative visual features under the guidance of the textual descriptions without harming their location ability - reformulates visual grounding as the problem of object bounding box coordinates regression conditioned on the query sentence.
Basic Visual and Textual Encoders: ResNet to extract image features and RNN based soft-parser to extract textual tokens (bi-directional LSTM is applied to encode the context for each word)
Grounding Encoder: 
Textual branch with self-attention
Visual Branch with Text-guided Self-attention
Grounding Decoder: Modified textual tokens serve as the grounding queries to decode the text-guided visual features
Prediction Head: Used for bounding box coordinate regression


Limitations of Existing Methods
Limited performance on complex, cluttered scenes
 Struggle with domain-specific terminology
 Computationally intensive for high-resolution images
 Lack of focus on satellite imagery domain
 Difficulty in handling multi-object relationships
 Limited interpretability of decisions
 Challenges in scaling to large datasets
